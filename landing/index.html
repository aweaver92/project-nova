Features

Everything an assistant should do — on your face, not in your hand.

Nova is built around a fast voice loop, then layered with the capabilities that make an assistant genuinely useful day to day. Almost all of it runs on-device.

🎙️

Low-latency voice

Streams glasses microphone audio to the OpenAI Realtime API and plays replies back through the glasses — with barge-in, persistent sessions, and latency metrics built in.

⚡

Skills & automations

Reusable voice macros with trigger phrases, variables, conditions, retries, webhooks, and delays. Schedule skills to run daily, and share them via JSON import/export.

🗂️

Workspaces & memory

Per-project workspaces with scoped conversation memory, background summarization into long-term digests, and continuity across sessions.

🔎

Knowledge search

Ask about anything you've saved — notes, bookmarks, facts, and past conversations — with blended keyword and semantic (embedding) search.

💻

Coding companion

Say "Nova, let me talk to Claude" and hand off coding tasks. Nova drives Claude Code and Cursor agents through the Nova Bridge, streams live progress, and can preview the result in your browser.

🏠

Smart home & actions

Query and control Home Assistant ("is the front door locked?"), draft emails and texts, create reminders, notes, and calendar events — all by voice.

💡

Proactive follow-ups

Suggestion chips after every reply — and optional spoken follow-ups — so conversations keep moving without you re-prompting.

🔐

Private by design

On-device stores for memory, skills, and knowledge. API keys never ship in the app — short-lived tokens are minted through your own bridge. Per-feature cost controls included.

👁️

Vision coming

"What am I looking at?" — camera-frame analysis and OCR read-back are wired into the architecture, waiting on Meta's device registration to unlock.

How it works

From your voice to an answer in a blink.

1

Speak through the glasses

Meta Ray-Ban microphones stream your voice to the Nova iOS app over Meta's Wearables Device Access Toolkit.

2

Nova thinks in real time

Audio streams to the OpenAI Realtime API. Nova injects your workspace context, long-term memory digest, and skill catalog so answers are personal and actionable.

3

Tools do the work

The tool router runs skills, searches your knowledge, drafts messages, controls your home, or pushes a coding task to Claude Code / Cursor through the bridge.

4

You hear the answer

The response streams back through the glasses' speakers. Interrupt any time — barge-in is native to the pipeline.

Architecture

Three parts, one contract.

Nova is built as clean Swift Package modules behind stable domain ports, validated first in a Windows simulator, and extended to your desktop through a small bridge service.

Nova/ iOS app

SwiftUI + MVVM over layered packages — NovaCore (errors, logging, latency), NovaDomain (ports, orchestrator, tools, memory), NovaData (DAT adapters, HFP audio, Realtime, Keychain), and NovaFeatures composed by a DI container.

nova-bridge/ desktop bridge

A small Node service on your dev machine: runs Claude Code headlessly, streams Cursor agent runs over SSE (with screenshots), serves live previews of generated projects on your LAN, and mints short-lived Realtime tokens.

nova-sim/ Windows sim

The same voice-loop domain contracts running against a PC microphone — resampling, barge-in, and tools — so conversation quality is validated before it ever touches the glasses.

Protocol-first. The AI provider sits behind a domain port — OpenAI today, swappable tomorrow. No vendor lock-in.
Sim-before-device. Every conversation-quality change lands in the Windows sim first, then swaps adapters on iOS.
Ephemeral credentials. The app holds no long-lived secrets; the bridge mints short-lived tokens on demand.
Roadmap

Where Nova is today.

Phases 1 and 2 shipped on-device with no new infrastructure. The rest is sequenced deliberately.

Shipped

Skills, workspaces, knowledge & memory

Voice macros, per-project memory, bookmarks, knowledge search, follow-up suggestions, and voice drafting — plus memory compaction, semantic search, scheduled skills, and skill sharing.

Mostly shipped

Actions & integrations

Home Assistant state queries and scenes, richer drafting (reminders with due dates, calendar events), and webhook/delay skill steps. Silent auto-send remains blocked by iOS sideload limits.

Blocked on Meta

Vision & camera

"What am I looking at?", OCR read-back, and visual memory are wired in the architecture — pending Meta AI companion-app registration for camera access.

Planned

Cross-device & multi-model

A sync backend for workspaces and memory, conversation handoff between glasses, phone, and desktop, and a Claude pipeline for long-form reasoning alongside the Realtime voice front-end.

FAQ

Questions, answered.

Do I need Meta Ray-Ban glasses to try Nova?

For the full experience, yes — Nova is designed around the glasses' microphones and speakers. But the voice pipeline also runs against your iPhone's mic, and the Windows simulator (nova-sim) lets you test conversation quality with just a PC and an OpenAI API key.

Is my data sent anywhere?

Voice audio streams to the OpenAI Realtime API during a conversation — that's the assistant. Everything else — memory, skills, notes, knowledge — is stored on-device. API keys never ship in the app; short-lived tokens are minted through a bridge you run yourself.

What does the Nova Bridge require?

A machine on your LAN running Node. It mints ephemeral Realtime tokens, runs Claude Code headlessly, streams Cursor agent progress, and serves previews of generated projects. It's optional — voice, skills, memory, and knowledge work without it.

Why isn't vision available yet?

Camera access on Meta Ray-Ban glasses requires Meta AI companion-app device registration, which is still gated. The vision ports, frame selector, and OCR read-back are already implemented behind the domain contracts, so they light up as soon as Meta unlocks access.

Can Nova use a different AI provider?

The AI layer is protocol-abstracted by design — OpenAI Realtime is the current adapter, but the domain logic doesn't know or care. A Claude pipeline for long-form reasoning is on the roadmap alongside the realtime voice front-end.

Is this an official Meta or OpenAI product?

No. Nova is an independent project built entirely on officially supported APIs: Meta's Wearables Device Access Toolkit and the OpenAI Realtime API.
